# OpenWallpaperEngine

**A free, lightweight animated wallpaper engine for Windows.**

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0.html)

## ✨ Features

- 🖼️ **Pictures** – set any `png / jpg / jpeg / bmp / webp` as a static wallpaper.
- 🎞️ **Video frame** – pick any frame of a video and use it as a static wallpaper.
- 🎬 **Animated** – use a video (`mp4 / mkv / avi / mov / webm`) as a live wallpaper:
  - Trim the clip (start / end) with live preview.
  - Optional audio from the video.
  - **Auto-mute** when other apps are playing sound.
  - Option to keep audio while the wallpaper is hidden behind windows.
  - Respects the Windows mute state.
- ⚡ **Lightweight** – drawing pauses automatically when a maximized/fullscreen window covers the desktop, hardware-accelerated decoding when available, late frames are skipped.
- 🚀 **Autostart** – animated wallpaper restarts with Windows.
- 💾 **Remembers your last choices.**

## 📦 Installation

### Option 1 – Download the installer (recommended)

1. Go to the [**Releases**](../../releases) page.
2. Download the latest installer and run it.

### Option 2 – Run / build from source

**Requirements:** Windows 10/11 and [Python 3.8+](https://www.python.org/downloads/) (tick *Add Python to PATH* when installing).

```bash
git clone https://github.com/PhucPower300121/OpenWallpaperEngine.git
cd OpenWallpaperEngine
pip install -r requirements.txt
python OpenWallpaperEngine.py
```

#### Build your own installer (optional)

1. Install PyInstaller:
   ```bash
   pip install pyinstaller
   ```
2. Run `build.bat` to build the executable.
3. Install [Inno Setup](https://jrsoftware.org/isinfo.php), open `create_installer.iss` and click **Compile**.
4. The installer will be generated by Inno Setup.

## 🚀 Usage

1. Open **OpenWallpaperEngine**.
2. Choose a tab on the left: **Pictures**, **Video frame** or **Animated**.
3. Click **Browse…** and select your file.
4. *(Animated)* Adjust the trim sliders and audio options.
5. Click **Apply**.

To stop the animated wallpaper, click **Stop animation**.

### Audio ignore list (optional)

Audio mixers / DSP apps (FxSound, Voicemeeter, Voicemod, Krisp, …) are ignored by the auto-mute feature. To add more, create:

```
%APPDATA%\OpenWallpaperEngine\ignore.txt
```

One exe name (or keyword) per line, e.g. `spotify`.

### Data & logs

Settings and logs are stored in `%APPDATA%\OpenWallpaperEngine` (`err.log` for errors).
